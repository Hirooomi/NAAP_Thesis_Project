Coded using the help of GEMINI ai PRO. NOTE: We are not formally educated in coding websites let alone one that uses AI. This is made for students of the NAAP specifically AMT students who will be taking their LICENSURE. 
Conventional learning apps and study centers are expensive and to help students in our campus, me and my team deviced this website to help them learn and prepare for FREE.

 In this code we have integrated a RAG SYSYEM that will simplify making time consuming task easier;
# PROF SIDE:
 Uploading a module that is aviation related only specific to his designated subject.
 Module editing, these function helps the professor add and remove contents, allowing them to create their own version to upload in the system repository.
 Test and flashcard creation and Editing, these function lets the professor to create questions of the difficulty with ease.

# Student SIDE:
 Students can easily search and ask questions in an window inside their home interface where the AI can guide them and give them the page number.
 Upon failing a test a student is given by the AI his own personal AI made flashcard, this also comes with the AIs assistance and advice prompting students to review a specific part they failed.

# ADMIN SIDE:
 Admins can create different accounts with ease, they may also send out alerts and have the server shut down. Admin has 3 levels which distinguish the power they have from being a helper to a person who is responsible for all functions.
